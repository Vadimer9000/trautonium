# ⚡ Траутониум (Trautonium & Mixturtrautonium) for Android

Цифровой винтажный инструмент в виде Android APK, воссоздающий легендарный электронный музыкальный инструмент 1929–1952 гг. конструкции **Фридриха Траутвейна** и **Оскара Сала**.

## 🎻 Особенности и возможности

1. **Струнный мануал (Wire Ribbon Controller)**:
   - Аутентичная нихромовая проволока над металлическим рельсом.
   - Непрерывное аналоговое микрохроматическое глиссандо и естественное пальцевое вибрато.
   - Динамическое усилие (Y-ось касания управляет силой нажима и открытием фильтра).
   - Переключение между режимами:
     - **Аналоговое глиссандо** (свободная микротоновая игра).
     - **Хроматический строй 12-TET** (с мягким портаменто).
   - Режим **Dual Manual (2 мануала)**: верхний соло-мануал и нижний бас-мануал для полифонии Оскара Сала.

2. **Блок субгармоник (Mixturwerk)**:
   - 4 независимых делителя базовой частоты: $f_0 / 1, f_0 / 2, f_0 / 3, f_0 / 4, \dots, f_0 / 24$.
   - Индивидуальные регуляторы громкости и формы волны (пила, меандр, треугольник, синус).
   - Точное отображение интервалов субгармонического ряда (унтертонов).

3. **Формантный блок фильтров (LC-резонанс)**:
   - Две перестраиваемые полосовые форманты ($F_1, F_2$) с регулировкой добротности $Q$ для имитации гласных звуков, струнных дек и колоколов.
   - Мастер-фильтр среза и резонанса.

4. **Аналоговый каскад и эффекты**:
   - Ламповый сатуратор (эмуляция триодов Telefunken RE-134).
   - Винтажный пружинный ревербератор.
   - Жидкостная педаль экспрессии (Swell pedal).
   - Эффект взмаха крыльев из фильма Альфреда Хичкока *«Птицы»* (1963).

5. **Осциллограф CRT-1930 и ламповые индикаторы**:
   - Зеленый фосфорный электронно-лучевой экран реального времени с сеткой и переключением Wave / FFT.
   - Анимированные вакуумные лампы с теплым накалом.

6. **Встроенный аудиорекордер**:
   - Запись исполненных композиций прямо в приложении с экспортом и скачиванием.

## 🎹 Исторические пресеты в комплекте
- **Oskar Sala Solo**: канонический тембр Mixturtrautonium ($f/1, f/2, f/3, f/5$) с вокальным формантом.
- **Птицы (The Birds 1963)**: жуткий металлический скрежет и шум крыльев из культового триллера Хичкока.
- **Виолончель Оскара Сала**: глубокий густой бас с октавным делением ($f/1, f/2, f/4, f/8$).
- **Кафедральный микстур-орган**: массивный полифонический субгармонический аккорд.
- **Ретро Терменвокс**: гладкое певучее глиссандо.
- **Электронный хор (A-O-U)**: ярко выраженные гласные форманты.

## 🛠 Сборка через GitHub Actions

В репозитории настроен автоматический CI/CD pipeline:
- При любом `git push` в ветку `main` автоматически собирается свежий Android APK.
- APK публикуется в артефактах GitHub Actions и GitHub Releases.
- (Опционально) При настроенных Secrets `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` файл APK автоматически присылается прямо в Telegram.

## 📱 Локальная сборка APK

```bash
# 1. Установка зависимостей
npm install

# 2. Сборка фронтенда
npm run build

# 3. Синхронизация Capacitor
npx cap sync android

# 4. Сборка APK
cd android
./gradlew assembleDebug
```
Файл APK будет доступен по пути: `android/app/build/outputs/apk/debug/app-debug.apk`.
